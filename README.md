## Project Overview

Tracking learning progress is essential for understanding how effectively time and effort are being spent across different skills. This project analyzes skill development data to evaluate learning progress, task completion, planned vs actual study hours, and performance scores.

The analysis transforms structured learning records into meaningful KPIs, Pivot Tables, and interactive Excel visualizations. It focuses on identifying completed and pending tasks, comparing planned learning time with actual hours spent, and evaluating progress across different skills.

The project goes beyond simple progress tracking by analyzing learning patterns and performance to highlight areas of strong progress and skills that may require additional focus.

## Objectives

- Track overall learning progress
- Analyze task completion and status
- Compare planned vs actual learning hours
- Analyze progress across different skills
- Evaluate performance scores
- Identify skills requiring additional focus
- Analyze progress over time
- Present findings through an interactive Excel dashboard
